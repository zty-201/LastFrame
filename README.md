A 3D Horror Game

Made by Team Cheerios as part of our 3rd year project.

1. Building
- Double click and run Configure_VisualStudio.bat for code analysis and asan, Run Configure_VisualStudio_No_Analysis.bat otherwise
- open up the .sln in generated build folder 
- run program

2. Level Editor
- Press on File and Open Scene to load the scene from json file
- Click on Interface Controls to open Control panel
- Under Manage we have different managers 
- Object manager allow us to select objects
- Asset Browser allow us to browse assets from the asset folder
- Debug profiler shows the current state of the engine (fps, running time etc.)
- Move around using wasd or up right left down and hold right mouse to look around
- Debug -> Show Debug Wireframe will display the mesh edges for debugging
